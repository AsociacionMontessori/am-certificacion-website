# 2. El punto más delicado: “internationally recognized certification”

Aquí sí me detengo.

Tu propuesta dice:

| Español                                 | English propuesto                        |
| --------------------------------------- | ---------------------------------------- |
| Certificación con validez internacional | internationally recognized certification |

Yo **no la aprobaría todavía** como fórmula pública, salvo que AMMAC tenga evidencia documental clara de ese reconocimiento internacional.

El problema no es lingüístico; en inglés suena natural. El problema es de **claim**:
**recognized by whom?**
¿AMI? ¿AMS? ¿MACTE? ¿escuelas afiliadas? ¿gobierno? ¿red de escuelas? ¿convenios?

“Internationally recognized” puede sonar a acreditación externa. Y justo tu propio glosario advierte que **compatible with MACTE / AMI** no debe convertirse en “accredited by”. 

## Mejor escala de seguridad

| Nivel                     | Fórmula                                                    | Cuándo usar                                                    |
| ------------------------- | ---------------------------------------------------------- | -------------------------------------------------------------- |
| Muy segura                | **AMMAC Montessori certification**                         | Siempre segura                                                 |
| Segura                    | **Montessori certification issued by AMMAC**               | Ideal para claims institucionales                              |
| Media                     | **international Montessori certification issued by AMMAC** | Si el programa realmente está dirigido a público internacional |
| Alta exigencia probatoria | **internationally recognized certification**               | Solo si puedes probar reconocimiento externo                   |
| Evitar                    | **certification with international validity**              | Calco raro y jurídicamente ambiguo                             |

Mi recomendación para el sitio:

> **Montessori certification issued by AMMAC**

Y si quieres conservar fuerza comercial:

> **International Montessori Guide certification issued by AMMAC**

Pero yo **no usaría “internationally recognized”** como frase base del glosario hasta que quede probado.

# 3. “Compatible with MACTE / AMI” también necesita blindaje

Tu glosario propone:

> **Compatible with MACTE / AMI** — NO “accredited by”.

Estoy de acuerdo con evitar “accredited by”, pero “compatible with” también puede prestarse a confusión. En inglés, “compatible with MACTE” podría sonar como si el curso fuera aceptable para MACTE, transferible o alineado formalmente.

Yo lo bajaría a una fórmula más segura:

| Actual                      | Mejor                                                                                        |
| --------------------------- | -------------------------------------------------------------------------------------------- |
| Compatible with MACTE / AMI | **aligned with international Montessori references and terminology**                         |
| Compatible with MACTE / AMI | **developed with reference to MACTE and AMI terminology/frameworks**                         |
| Compatible with MACTE / AMI | **not affiliated with, accredited by, or endorsed by MACTE or AMI**, si necesitas disclaimer |

Fórmula para glosario:

| Compatible con MACTE / AMI | **aligned with international Montessori references** / **developed with reference to MACTE and AMI terminology** | Do not write “accredited by,” “recognized by,” “endorsed by,” or “equivalent to” unless formally documented. Avoid “compatible with” in public-facing claims unless the exact meaning of compatibility is explained. |

Y otra:

Versión sugerida:

```md
- Preserve keys, URLs, routes, slugs, emails, phone numbers, Markdown links, escaped characters, `\n`, ICU variables, and all placeholders exactly.
- Do not translate component tags or attributes. Translate only visible text between tags.
```
